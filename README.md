# Suprlir
SUPRLIR 🔴⚡ est une application Android au design noir et rouge qui conserve les notifications WhatsApp pour consulter les messages supprimés lorsqu'ils ont été enregistrés. Elle propose un code PIN, un historique, une corbeille de 30 jours et l'export PDF. Disponible en français et anglais, au prix unique de 500 FCFA.
